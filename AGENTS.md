Project Instructions for AI Coding Agents
Frontend Rules

Before creating, modifying, or reviewing frontend UI/UX, read and follow FRONTEND_RULES.md.

These rules govern frontend design, styling, components, animations, visual assets, website copy, responsive behavior, accessibility, and production website launch preparation.

Apply the rules proactively to all relevant frontend tasks. Review the relevant requirements before finishing frontend changes.

Scope
Apply FRONTEND_RULES.md only to frontend UI/UX work.
Do not apply frontend-specific design restrictions to unrelated backend logic, APIs, databases, or infrastructure.
For full-stack tasks, apply the frontend rules to frontend changes and follow the existing project instructions for backend changes.
Verification

Do not claim that a rule has been followed, a test has passed, or a launch requirement has been completed unless it has been verified.

If a required check cannot be completed, state what remains outstanding.
